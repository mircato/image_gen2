# قصاقيص الدول

لكل دولة:
1. ابعت لكوديكس القالب `masks/<ISO>.png` مع البرومبت بتاعها من `prompts/<ISO>.txt` (أو من `prompts.md`).
2. احفظ الصورة اللي يرجّعها في `in/<ISO>.png` بنفس الاسم بالظبط (مثلاً `in/EGY.png`).

مش لازم تخلّصهم كلهم مرة واحدة: كل ما تحط صور قولّي، وأنا أقصّهم وألزقهم على الكرة.
